# Kokoonpanot

**Kokoonpanot**-välilehdellä tarkistetaan joukkueet ennen kuulutusta. Valitse ylhäältä **Vieras** tai **Koti**.

## Tulospalvelusta

Pelaajat, pelipaikat, kapteenit ja valmentajat haetaan TiTusta automaattisesti, kun ottelu valitaan. Toimitsijat syöttävät kokoonpanot yleensä vähän ennen ottelua. Jos lista on tyhjä tai vajaa, paina myöhemmin **↻ Tulospalvelusta**. Huom: uudelleenhaku korvaa käsin tehdyt muutokset ja kenttäjaon.

Joukkueen nimeä voi muokata ylhäällä, jos haluat sen kuulutettavan eri muodossa (esim. ”HyRi Keltainen”).

## Maalivahdit

Valitse **Aloittava** (jos tiedossa) ja **Varamaalivahti**. Maalivahdit kuulutetaan ohjeen mukaan ensin, aloittava ennen varamaalivahtia.

## Kentälliset

Junioriotteluissa TiTussa ei yleensä ole kenttäjakoa. Silloin kokoonpano kuulutetaan **pelipaikoittain**: maalivahdit ja sitten kenttäpelaajat numerojärjestyksessä. Tämä on ohjeen mukainen tapa, eikä kenttiä tarvitse merkitä.

Jos kentät ovat tiedossa (esim. ottelupöytäkirjasta):

- **+ Kenttä** lisää kentän, jolle valitaan puolustajat ja hyökkääjät.
- **Esitäytä** arvaa kentät pelipaikan ja numerojärjestyksen mukaan. Korjaa ne aina pöytäkirjan mukaan.
- **Tyhjennä** poistaa kentät, jolloin kuulutus palaa pelipaikoittaiseksi.
- Samaan paikkaan kahdesti valittu pelaaja näkyy punaisena.

## Pelaajat

| Sarake | Merkitys |
|---|---|
| # | Pelinumero |
| Etunimi / Sukunimi | Kuulutettava nimi |
| Ääntämys | Kirjoita nimi niin kuin se lausutaan, jos ääni lausuu sen väärin. Katso [Äänet ja ääntämys](Aanet-ja-aantamys.md). |
| Paikka | MV = maalivahti, P = puolustaja, H = hyökkääjä, KP = kenttäpelaaja |
| K | C = kapteeni, A = varakapteeni |

- **+ Pelaaja** lisää rivin.
- **Liitä lista** lisää monta pelaajaa kerralla. Kirjoita yksi pelaaja riville muodossa `numero etunimi sukunimi [MV|P|H] [C|A]`, esim. `19 Kalle Korhonen H C`. Jos numero on jo listalla, sen pelaaja päivitetään.
